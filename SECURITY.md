# Politique de sécurité

Merci de ne pas publier les vulnérabilités dans une issue publique. Contactez le
mainteneur du dépôt en privé avec la version concernée, les étapes de
reproduction et l’impact observé.

Cellier doit être exposé uniquement sur un réseau de confiance ou via VPN. Les
secrets restent dans `.env`, qui est ignoré par Git. N’ajoutez jamais un export,
une facture, une sauvegarde ou un jeton Home Assistant au dépôt.
